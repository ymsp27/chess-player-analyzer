# Piece Templates

Add 12 PNG images here, one for each piece:

- white_pawn.png
- white_knight.png
- white_bishop.png
- white_rook.png
- white_queen.png
- white_king.png
- black_pawn.png
- black_knight.png
- black_bishop.png
- black_rook.png
- black_queen.png
- black_king.png

Best results come from crops taken from the same chess website/app/theme
as the screenshots you want to analyze.

The crop should contain the piece and enough of its square/background to
match the screenshots.

The first image-recognition version is deliberately simple. It is a
foundation for later replacement with a trained piece classifier.
